# Облік показників лічильників

Консольна програма для мешканця, який раз на місяць записує показники лічильників (вода, газ, електрика)
і хоче бачити споживання за місяць та суму до сплати. Потрібен Python 3.10+, зовнішніх залежностей для роботи немає.

    python -m meters add water-1 1000 2026-09-30      # додати показник
    python -m meters consumption water-1 2026-10      # споживання за жовтень 2026

Нижче: [як зібрати з нуля](#як-зібрати-з-нуля), [команди](#команди), [ліцензія](#ліцензія).

## Як зібрати з нуля

Linux / macOS:

    git clone <адреса-репозиторію> tspp-makeup-kryvko
    cd tspp-makeup-kryvko
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    make check                  # лінтер + тести (те саме, що робить CI)

Windows (PowerShell): замість `source .venv/bin/activate` — `.venv\Scripts\Activate.ps1`; замість `make check` —
`ruff check .` і потім `python -m pytest -q` (на Windows `make` зазвичай не встановлений).

Тільки тести: `python -m pytest -q`. Тільки лінтер: `ruff check .`.

Дані зберігаються у `data.json` у поточній теці. Інший шлях — змінна оточення `METERS_DATA`.
Журнал роботи (INFO/ERROR) виводиться у стандартний потік помилок, результат команди — у стандартний вивід.

## Команди

| Команда                                  | Що робить                                                  |
|------------------------------------------|------------------------------------------------------------|
| `add <лічильник> <значення> <YYYY-MM-DD>` | додає показник; від'ємне значення — помилка               |
| `consumption <лічильник> <YYYY-MM>`       | споживання за місяць                                      |
| `bill <YYYY-MM> <тариф за одиницю>`       | сума до сплати за місяць за всіма лічильниками            |
| `anomalies`                               | показники, що менші за попередні або зросли більш ніж на 500 |

### Контракт: `consumption`

Споживання — різниця між останнім показником місяця і останнім показником перед початком місяця
(якщо попереднього немає — між останнім і першим показником самого місяця).

    $ python -m meters add water-1 1000 2026-09-30
    OK
    $ python -m meters add water-1 1060 2026-10-31
    OK
    $ python -m meters consumption water-1 2026-10
    60.0

Неіснуючий місяць (`2026-13`) — помилка `ValueError`, лічильник без показників за місяць — `0`.

### Контракт: `bill`

Сума споживання всіх лічильників за місяць, помножена на тариф за одиницю, округлена до копійок.

    $ python -m meters bill 2026-10 2.5
    150.0

(для даних із прикладу вище: `60.0 × 2.5`).
