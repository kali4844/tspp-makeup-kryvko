# Облік показників лічильників

Консольний облік показників лічильників (вода, газ, електрика): додати показник і порахувати споживання за місяць.

Запуск (потрібен Python 3.10+):

    python -m meters add water-1 1000 2026-09-30
    python -m meters consumption water-1 2026-10

Дані зберігаються у `data.json` у поточній теці (інший шлях — змінна `METERS_DATA`).
